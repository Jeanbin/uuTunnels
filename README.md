# uuTunnels

> 轻量级单文件内网端口映射管理控制台（**当前仅支持 Windows x86_64**）。  
> 基于 **「网易 UU 远程 + 单一 SSH 基座 + `direct-tcpip` 多路复用」**，集中管理多台内网主机与几十个端口服务，并提供托盘常驻、纯黑终端字符风格 Web 控制台，以及 UU 远程端口映射窗口防误关一键收纳能力。

---

## 一、前置依赖与架构声明（必读）

> **⚠️ 本工具必须搭配「网易 UU 远程」使用，不能脱离 UU 远程独立完成公网穿透。**

1. **穿透通道依赖声明**：
   - 本项目的内网穿透底层通道基于 **网易 UU 远程**，你需要在 Windows 本机安装并登录 **网易 UU 远程（主控端）**。
   - **被控端 Linux 环境声明**：本方案中 Linux 被控端使用的是开源项目 **[VallierDev/uu-remote-linux](https://github.com/VallierDev/uu-remote-linux)**（非官方 UU 远程 Linux 被控端）。通过该工程在内网 Linux 主机（或 NAS 虚拟机、Docker/宿主机环境）运行 UU 被控服务后，即可利用网易 UU 远程打通 P2P / 中继内网穿透链路。
2. **工作拓扑**：

```text
┌───────────────────┐     本地 127.0.0.1:8080/5000/...     ┌───────────────────────┐
│  浏览器 / SSH 终端  │ ──────────────────────────────────▶ │    uuTunnels.exe      │
│  / 数据库 / Git    │                                     │  (SSH direct-tcpip    │
└───────────────────┘                                     │   多路复用 + 托盘管理)  │
                                                           └───────────┬───────────┘
                                                                       │ 仅走 1 条本地 SSH 基座端口 (如 127.0.0.1:2201)
                                                                       ▼
┌─────────────────────────────────┐    网易 UU 远程穿透    ┌───────────────────────┐
│ Linux 被控端                     │ ◀══════════════════▶ │   网易 UU 远程 客户端   │
│ (VallierDev/uu-remote-linux)    │    (仅维护 1 条映射)   │  (支持一键后台隐藏收纳) │
└───────────┬─────────────────────┘                        └───────────────────────┘
            │ 经 SSH 隧道转发至本机或同局域网其他设备
            ├──▶ Linux 本机服务 (127.0.0.1:8080 / 8443 / 22 ...)
            └──▶ 同局域网 NAS / 路由器 / Git (192.168.1.100:5000 / 22 ...)
```

3. **系统平台限制**：
   - **当前仅支持 Windows（x86_64）**：因为窗口防误关收纳（Win32 `EnumWindows` / `ShowWindow` 隐藏 `GameViewer.exe` 端口映射子窗口）、系统托盘（`tray-icon`）与开机自启（`HKCU\...\Run`）均为 Windows 原生实现，暂未提供 macOS / Linux 客户端。

## 二、为什么使用并最终选择这个方案？

在长期远程访问家庭/公司内网环境（Linux 虚拟机 + 同局域网 NAS / Docker 服务）的实践中，对比了几种常见内网穿透方式：

| 方案对比 | 痛点与局限 |
|---|---|
| **传统 frp / WireGuard / 自建 VPS 中转** | 需要购买维护公网云服务器与流量带宽，小带宽服务器大文件或 Web 资源加载慢，还涉及域名、证书、公网安全暴露面等问题。 |
| **直接在「网易 UU 远程」中配置十几条端口映射** | 1. 每加一个内网端口都要在 UU 界面手工新增/开关；<br>2. 跨设备访问同局域网另一台机器（如 NAS Web、内网 Git）管理分散；<br>3. UU 远程的端口映射弹窗独立挂在任务栏，**一旦误点右上角 `×` 就会直接断开所有映射**；<br>4. 缺乏分组管理、独立规则开关、安全入口路径后缀、端到端测通以及实时连接数/速率统计。 |
| **手写 `ssh -L` 命令行脚本** | 开一条命令只能固定一组端口，动态增删某个服务必须重启整个 SSH 会话；断线重连、多机分组、快捷打开带安全路径的 HTTPS 地址、收纳 UU 窗口都要自己拼脚本。 |

**为什么最终选择了「网易 UU 远程 + `uu-remote-linux` + 单一 SSH 基座（`uuTunnels`）」方案：**

1. **零公网服务器成本**：借助网易 UU 远程 + [VallierDev/uu-remote-linux](https://github.com/VallierDev/uu-remote-linux) 直接利用 UU 成熟稳定的内网穿透通道，不需要额外维护公网中转 VPS。
2. **化繁为简（N 条 → 1 条）**：整个 UU 远程里**只需要创建并保持 1 条到 Linux 被控端 SSH（22 端口）的映射**。后续无论新增多少个 Web 后台、NAS 管理页、Git 仓库还是 SSH 终端，全部由 `uuTunnels` 在本地通过这条 SSH 隧道进行 `direct-tcpip` 多路复用分发。
3. **规则热插拔，互不干扰**：每条映射规则独立绑定本地监听端口并复用同一条 SSH 基座连接；随时单开或单关某一条服务，不会影响其他正在传输的终端或网页连接，SSH 断开也会按 2s–10s 退避自动重连并保持 15s keepalive。
4. **防误关保护 + 无打扰托盘运行**：专门识别 `GameViewer.exe` 窗口句柄，只隐藏 UU 的端口映射/设备子窗口而保留 UU 主窗口；托盘图标随基座/规则健康度动态变色，管理界面直接用系统默认浏览器打开，关掉浏览器标签页后隧道依然在后台稳定运行。

## 三、核心特性

- **多基座支持**：支持 **SSH 隧道基座**（密码或私钥认证 + RTT 实时 ping 检测）、**SOCKS5 代理基座** 与 **直连（Direct）模式**。
- **按机器分组管理**：在「隧道基座 → 机器节点 → 独立映射规则」三层结构下，既可映射 Linux 被控端本机端口（`127.0.0.1`），也可经 Linux 跳板访问同局域网内的 NAS、路由器或其他主机。
- **每条规则独立掌控**：
  - 独立 `[■ ON ]` / `[  OFF]` 开关、本机一键全开/全关、全局全部开启/关闭
  - `[★]` 置顶规则直达 Windows 系统托盘右键菜单，不用打开网页也能快速切换常用端口
  - `[测通]` 端到端连通性探测（支持 HTTP `HEAD` 与 SSH Banner 检测）、`[复制]`、`[复制SSH]`、`[>_终端]`（每条 SSH 规则可独立配置用户名、密码或私钥路径/口令，并可从下拉或设置弹窗选择 **Xshell、MobaXterm、PuTTY、KiTTY、SecureCRT、Electerm、Windows Terminal、PowerShell 7 / Windows PowerShell、CMD、Git Bash、系统 `ssh://` 协议或自定义命令模板**）
- **HTTP / HTTPS 访问路径后缀（`url_path`）**：支持为带安全入口路径的后台（如 `/admin`、`/43235a23` 等）配置后缀，点击 `[打开↗]` 或 `[复制]` 时自动拼接完整 URL；仅修改后缀不重启现有监听连接。
- **UU 远程窗口防误关收纳**：一键将 `GameViewer.exe` 的端口映射子窗口隐藏到后台（或开启「基座连上自动收纳」），退出 `uuTunnels` 或点击「恢复窗口」时自动还原。
- **纯黑 CMD / Windows Terminal 字符拼接 TUI**：`#0c0c0c` 纯黑背景、全字符边框与方括号操作控件、零外部前端依赖，直接内嵌编译为单个 `.exe` 可执行文件（约 4.5 MB）。

## 四、快速上手（4 步完成）

### 第 1 步：在 Linux 被控端部署 `uu-remote-linux`
参考开源项目 [VallierDev/uu-remote-linux](https://github.com/VallierDev/uu-remote-linux) 的文档，在你的内网 Linux 主机 / 虚拟机上安装并绑定网易 UU 远程账号。

### 第 2 步：在 Windows 网易 UU 远程中建立 1 条 SSH 基座映射
1. 打开 Windows 版「网易 UU 远程」，找到你的 Linux 被控端设备；
2. 打开该设备的 **端口映射** 功能，添加 **1 条** 映射规则并启用：
   - **本地地址/端口**：`127.0.0.1:2201`
   - **远端目标端口**：`22`（Linux SSH 服务端口）
3. 以后无需再在 UU 远程界面维护其他业务端口。

### 第 3 步：下载并运行 `uuTunnels`（Windows 绿色包）
1. 前往本仓库的 **Releases** 页面下载最新的 Windows 绿色压缩包（例如 `uuTunnels-v0.3.0-windows-x86_64.zip`），解压到任意目录；
2. 双击运行 **`uuTunnels.exe`**；
3. 程序会在右下角系统托盘常驻，并自动使用系统默认浏览器打开控制台：`http://127.0.0.1:17890/`；
4. 在 **「[1] 隧道基座」** 点击 **`[ 编辑凭据 ]`**，核对主机/端口（默认 `127.0.0.1:2201`）、填写你的 Linux SSH 用户名及密码（或私钥路径），点击 **`[ 保存并连接 ]`**；
5. 在 **「[2] 机器与独立端口映射规则」** 中按需编辑或添加你的内网服务规则，拨动 **`[■ ON ]`** 即可本地访问。

### 第 4 步：收纳 UU 端口映射窗口
- 在页面顶部或托盘菜单点击 **`[ >_ 收纳 UU 窗口 ]`**，也可勾选 **`[x] 基座连上自动收纳`**，即可将 UU 端口映射窗口安全隐藏到后台，防止误关 `×` 导致链路中断。

## 五、命令行参数与配置文件

### 命令行参数
- `--no-open`：仅在后台启动并驻留托盘，不自动打开浏览器管理页面（在界面启用「开机自启」时，写入启动项的命令会自动携带此参数）
- `--ui-port <端口>`：指定本地 Web 控制台端口（默认 `17890`）
- `--config <路径>`：指定自定义配置文件路径

### 配置文件位置
首次启动会在系统配置目录自动生成模板配置（含 1 个示例基座、2 个示例节点及 7 条默认关闭的示例规则）：
```text
%APPDATA%\uuTunnels\config.json
```

> **🔒 安全提示**：
> 1. 配置中的 SSH 密码与私钥口令以明文保存在本地 `%APPDATA%\uuTunnels\config.json` 文件中（Web API `/api/state` 仅返回 `has_password` / `has_key_passphrase` 布尔标记，不会下发给前端）；请妥善保管本机配置目录权限。
> 2. 当前内网基座直连场景下，SSH 客户端 `check_server_key` 默认接受服务端主机公钥（适用于经过 UU 加密点对点隧道的受控内网场景）。

## 六、从源码编译（Windows）

环境要求：Rust stable toolchain（`x86_64-pc-windows-msvc`）+ Visual Studio C++ Build Tools（无需额外安装 CMake / Node.js，加密栈采用纯 Rust 的 `russh` + `ring` + `rsa`）。

```powershell
# 运行单元测试（建议限制并发 -j 2）
cargo test -j 2

# 编译 Release 单文件绿色版
cargo build --release -j 2
```

编译产物位于：`target\release\uuTunnels.exe`。
